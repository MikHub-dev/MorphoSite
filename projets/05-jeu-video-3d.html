Question 1

Comment un personnage existe-t-il dans l'ordinateur ?

Sous forme de points : des milliers de petits sommets, reliés en triangles, qui dessinent la peau, les vêtements, l'épée. Chaque point est repéré par trois nombres (x, y, z) : sa position à droite, en haut et en profondeur.

Les maths derrière : les coordonnéesM = (x, y, z)

Un repère, c'est une origine et trois directions. Tout point de l'espace s'écrit alors avec trois nombres.

📖 Dans le livre : ch. 5, Station 1 : vecteurs et translations, p. 56
Un modèle 3D : des sommets et des arêtes
2
Question 2

Comment le faire avancer d'un pas ?

Un pas, c'est une flèche : « 1 vers la droite, 0 vers le haut, 2 vers le joueur ». On l'ajoute aux coordonnées de chaque point. Le héros, en (2, 0, 5), se retrouve en (3, 0, 3).

Les maths derrière : le vecteur et la translation(2, 0, 5) + (1, 0, −2) = (3, 0, 3)

Un vecteur représente un déplacement : une direction, un sens, une longueur. Translater un point M d'un vecteur v, c'est calculer M + v.

📖 Dans le livre : ch. 5, cas concret « le moteur de jeu vidéo 3D », p. 60
La même flèche pour chaque point
3
Question 3

Pourquoi le personnage ne se déforme-t-il pas ?

Parce que tous ses points reçoivent la même règle. Les distances entre la main et l'épaule, entre les pieds et la tête, restent les mêmes : le héros bouge d'un bloc, comme un objet rigide. Il n'y a jamais besoin de recalculer sa forme.

Les maths derrière : l'isométried(f(A), f(B)) = d(A, B)

Une transformation qui conserve toutes les distances s'appelle une isométrie. Translations et rotations en sont : elles changent la place, jamais la forme.

φ Morphisme : conserver les distances = conserver la forme 📖 Dans le livre : ch. 5, Déplacer sans déformer, p. 54
Changer de place, pas de forme
4
Question 4

Et pour le faire tourner ou grandir ?

On utilise un tableau de nombres, une matrice, qui dit comment mélanger x, y et z. Pour un quart de tour dans le plan, (x, y) devient (−y, x). Pour doubler la taille, on multiplie tout par 2. Une matrice, une transformation.

Les maths derrière : applications linéaires et matrices(x, y) ⟼ (−y, x)

Une application linéaire est entièrement fixée par ce qu'elle fait sur les axes : quelques nombres suffisent (chapitre 1). Composer deux transformations revient à multiplier leurs matrices.

φ Morphisme : application linéaire ↔ matrice 📖 Dans le livre : ch. 5, Station 3, « application linéaire et matrice », p. 57
La matrice du quart de tour
5
Question 5

Peut-on aussi écrire « avancer » avec une matrice ?

Hélas, non, pas directement ! Une matrice laisse toujours l'origine sur place : (0, 0, 0) reste en (0, 0, 0). Or avancer déplace tout, origine comprise. La translation n'est pas linéaire : elle est seulement affine.

Les maths derrière : linéaire ou affinef(0) = 0 pour toute application linéaire

C'est la différence vue au chapitre 1 entre x ↦ 3x (linéaire) et x ↦ 3x + 2 (affine). Le « + 2 » déplace l'origine.

📖 Dans le livre : ch. 5, Station 1, « un problème caché », p. 56
La droite affine ne passe pas par l'origine
6
Question 6

Comment les moteurs de jeu s'en sortent-ils ?

Avec une astuce : on ajoute une quatrième coordonnée, toujours égale à 1. Le point (x, y, z) devient (x, y, z, 1). Dans ce monde à quatre dimensions, avancer s'écrit avec une matrice 4 × 4, et le déplacement se range dans la dernière colonne.

Les maths derrière : les coordonnées homogènes(x, y, z, 1) ⟼ (x + a, y + b, z + c, 1)

On plonge ℝ³ dans ℝ⁴. La translation par (a, b, c) devient une vraie application linéaire de ℝ⁴. La dernière ligne (0, 0, 0, 1) recopie simplement le 1.

φ Morphisme : une translation devient linéaire en coordonnées homogènes 📖 Dans le livre : ch. 5, Station 3, les coordonnées homogènes, p. 57
La matrice de translation 4 × 4

Question 7

Comment enchaîner « tourner » puis « avancer » ?

On multiplie les deux matrices une seule fois : M = T × R. Puis on applique M à chacun des dizaines de milliers de sommets, 60 fois par seconde. Attention à l'ordre : tourner puis avancer ne donne pas la même chose qu'avancer puis tourner.

Les maths derrière : la composition et le produit de matricesM = T × R ≠ R × T

Composer deux transformations, c'est multiplier leurs matrices. Comme pour les fonctions du chapitre 1, l'ordre compte : la composition n'est pas commutative.

📖 Dans le livre : ch. 5, cas concret, la matrice modèle, p. 60
Deux gestes, une seule matrice
8
Question 8

Comment passer du monde du jeu à l'image sur l'écran ?

Par trois matrices en chaîne. La matrice « modèle » place l'objet dans le monde. La matrice « vue » le regarde depuis la caméra. La matrice « projection » l'aplatit sur l'écran. Afficher une image, c'est composer ces trois transformations, des millions de fois par seconde, sur la carte graphique.

Les maths derrière : la chaîne de morphismesécran = Projection × Vue × Modèle × point

Le processeur graphique (GPU) est conçu pour une seule chose : multiplier des matrices 4 × 4 par des vecteurs, des milliards de fois par seconde.

📖 Dans le livre : ch. 5, cas concret, modèle, vue, projection, p. 60
La projection, elle, aplatit

Deux pas en avant

Le héros part de (2, 0, 5) et fait deux pas de (1, 0, −2). Où arrive-t-il ? Quelle est la matrice 4 × 4 qui fait les deux pas d'un coup ?

Voir la réponse

Il arrive en (4, 0, 1). Deux pas font une seule translation de (2, 0, −4) : la matrice a pour dernière colonne (2, 0, −4, 1), avec des 1 sur la diagonale et des 0 ailleurs.
