Voir l'intérieur d'un corps sans l'ouvrir

Un scanner ne voit jamais l'intérieur du corps : il ne mesure que des ombres. Et pourtant, l'image finale montre chaque organe au millimètre. Huit questions pour remonter des ombres à l'image.

Question 1

Que mesure un rayon X qui traverse le corps ?

Il ressort affaibli. Plus il a traversé de matière dense (os, organes), plus il a perdu d'énergie. Le capteur ne donne qu'un nombre par rayon : l'affaiblissement total, cumulé tout au long du trajet. Comme une ombre.

Les maths derrière : l'intégrale le long d'une droitemesure = ∫ densité le long du rayon

Une intégrale cumule une quantité le long d'un chemin. Une seule mesure ne dit pas où se trouve la matière, seulement combien il y en a sur la ligne.

📖 Dans le livre : ch. 23, Station 1 : intégrale et systèmes linéaires, p. 208
Une ombre, un nombre
2
Question 2

Pourquoi une seule radiographie ne suffit-elle pas ?

Parce qu'une ombre écrase tout sur un plan. Une petite tache dense devant ou derrière un os donne la même ombre. Pour savoir où sont les choses, il faut regarder sous plusieurs angles, et croiser les ombres.

Les maths derrière : plusieurs projectionsune direction ⟶ une projection

Chaque direction de rayons donne une « projection » du corps : la liste des sommes le long de toutes les lignes parallèles.

📖 Dans le livre : ch. 23, Ouverture : reconstruire un volume à partir de ses ombres, p. 208
Croiser les directions
3
Question 3

Sur une image minuscule, comment cela marche-t-il ?

Prenons une image de 2 × 2 pixels, de densités inconnues a, b, c, d. Les rayons donnent : ligne du haut a + b = 10, ligne du bas c + d = 6, colonne de gauche a + c = 9, et une diagonale a + d = 8. Quatre inconnues, et des équations qui les relient.

Les maths derrière : un système linéairea + b = 10 ; c + d = 6 ; a + c = 9 ; a + d = 8

Chaque mesure est une équation du premier degré. Retrouver l'image, c'est résoudre ce système.

📖 Dans le livre : ch. 23, cas concret « reconstruire une image à partir de trois projections », p. 212
Quatre pixels inconnus
4
Question 4

Comment retrouver les quatre densités ?

Pas à pas. De a + d = 8 : d = 8 − a. De c + d = 6 : c = a − 2. De a + c = 9 : 2a − 2 = 9, donc a = 5,5. Puis c = 3,5, d = 2,5 et b = 10 − 5,5 = 4,5. Vérification avec un rayon de plus : b + d = 7, c'est bien la mesure.

Les maths derrière : la résolution par substitutiona = 5,5 ; b = 4,5 ; c = 3,5 ; d = 2,5

On exprime une inconnue en fonction d'une autre, on remplace, et on remonte. Une mesure supplémentaire sert de contrôle.

📖 Dans le livre : ch. 23, cas concret, la résolution, p. 212
L'image est retrouvée

Question 5

Quel est le lien général entre une image et ses ombres ?

Le passage image → ombres est facile : on additionne le long des rayons. C'est ce que fait la machine. Le passage ombres → image est l'inverse, plus délicat, mais possible si on a assez d'angles. Ce va-et-vient porte un nom : la transformée de Radon, inventée en 1917, utilisée par le premier scanner en 1971.

Les maths derrière : la transformée de Radon et son inverseimage ⟼ {projections sous tous les angles}

La transformée de Radon associe à une densité du plan toutes ses intégrales le long des droites. Elle est inversible : on peut recomposer l'image.

Un aller facile, un retour possible

Question 6

Un vrai scanner résout-il un système de millions d'équations ?

Pas directement, ce serait beaucoup trop long. Il utilise une méthode astucieuse, la rétroprojection filtrée : on « renvoie » chaque ombre à travers l'image dans sa direction, on additionne toutes ces traînées, après les avoir filtrées pour qu'elles ne brouillent pas l'image.

Les maths derrière : la rétroprojection filtréeimage ≈ Σangles (ombre filtrée, étalée)

Un algorithme d'inversion efficace remplace la résolution d'un système géant. Le filtrage utilise les fréquences du chapitre 20.

📖 Dans le livre : ch. 23, cas concret, la rétroprojection filtrée, p. 212
La recette du scanner

Question 7

Que se passe-t-il si les mesures sont un peu fausses ?

Danger : remonter des effets aux causes amplifie les erreurs. Une toute petite erreur de mesure peut créer une grosse tache fantôme sur l'image. On dit que le problème est mal posé. Le filtrage sert justement à limiter les dégâts, en acceptant une image un peu plus floue mais fiable.

Les maths derrière : un problème mal posépetite erreur sur les mesures ⟹ grande erreur possible sur l'image

Pour un problème inverse, on ne cherche pas une inversion exacte mais une approximation à erreur maîtrisée (chapitre 10).

📖 Dans le livre : ch. 23, Sous le capot : un problème mal posé, p. 213
Inverser sans précaution amplifie les erreurs
8
Question 8

Peut-on « scanner » l'intérieur de la Terre ?

Oui ! Après un séisme, des capteurs du monde entier mesurent le temps d'arrivée des ondes qui ont traversé la planète par des chemins différents. Ces temps jouent le rôle des ombres. En les inversant, on voit le manteau terrestre à des milliers de kilomètres sous nos pieds.

Les maths derrière : la tomographie sismiquetemps de trajet = ∫ lenteur le long du chemin

Même principe : chaque mesure est une intégrale le long d'un trajet ; l'inversion révèle la répartition de ce qui ralentit les ondes.

📖 Dans le livre : ch. 23, cas concret, la tomographie sismique, p. 212

Un autre mini-scanner

Une image 2 × 2 donne : a + b = 7, c + d = 9, a + c = 6, a + d = 5. Retrouve a, b, c, d et vérifie avec b + d.

Voir la réponse

d = 5 − a, c = 9 − d = 4 + a, a + c = 2a + 4 = 6 donc a = 1. Puis c = 5, d = 4, b = 6. Contrôle : b + d = 10, et a + b + c + d = 16 = 7 + 9.
